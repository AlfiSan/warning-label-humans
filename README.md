A program that writes the funniest single-line safety warning label that should come printed on every human being. One line, 129 characters, funny first and plausible second: everybody knows someone who says "I'm five minutes away" while nowhere near leaving, and the label lets that excuse quietly fall apart in its last few words.

## Run it

```sh
node main.ts
```

This writes the label to `/output/entry.txt` — exactly one line, 129 characters, no trailing newline. No network, no dependencies, same bytes on every run. The program checks the line against the bounty's own limits (1–160 characters, single line, more than whitespace) before writing, and refuses to write anything that would fail the gate.
